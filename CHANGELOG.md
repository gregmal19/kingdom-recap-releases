# Changelog

Condensed version history for Kingdom Recap. Full notes and downloads for every
version live on the [Releases](../../releases) page.

## 1.2.0 (2026-08-31)

- Commander portraits now display out of the box — no setup needed.

## 1.1.0 (2026-08-31)

Invite-only builds.

- One-time activation code on first launch. The code comes with your invite,
  works once, and needs an internet connection for that single moment; after
  that the app runs fully offline and reinstalls re-activate automatically.
- The commander-portraits folder setting was removed from the Settings page;
  commanders without local artwork show as initials.

## 1.0.0 (2026-08-28)

First public release.

- Battle analytics for PvP and PvE, built from the game's own battle reports.
- Resource gathering and kill point tracking per player and per account.
- Automatic scanning of the Rise of Kingdoms mail cache, with a live folder
  watcher and a polling fallback.
- Progress Companion for planning commander loadouts.
- Light and dark themes.
- Windows installer with desktop and start menu shortcuts.
